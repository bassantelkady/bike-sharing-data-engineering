# Data Dictionary – Bike Sharing Dataset

| Column | Description | Data Type |
|---|---|---|
| instant | Unique record identifier | Integer |
| dteday | Date of bike rental | Date |
| season | Season code (1–4) | Integer |
| yr | Year code (0–1) | Integer |
| mnth | Month (1–12) | Integer |
| hr | Rental hour (0–23) | Integer |
| holiday | Holiday indicator | Integer |
| weekday | Day of the week | Integer |
| workingday | Working day indicator | Integer |
| weathersit | Weather condition code | Integer |
| temp | Normalized temperature | Float |
| atemp | Normalized feeling temperature | Float |
| hum | Normalized humidity | Float |
| windspeed | Normalized wind speed | Float |
| casual | Number of casual rentals | Integer |
| registered | Number of registered rentals | Integer |
| cnt | Total number of rentals | Integer |

## Dataset Information

- Dataset Name: Bike Sharing Dataset
- Source: UCI Machine Learning Repository
- Number of Records: 17,379
- Number of Columns: 17
- Frequency: Hourly
- Period: 2011–2012
